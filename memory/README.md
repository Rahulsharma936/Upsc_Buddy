# Project Memory System

This folder acts as a persistent memory bank for all conversations, feature implementations, and system changes in the **UPSC Buddy** project.

## Structure

- **[`session_history.md`](./session_history.md)**: Chronological record of conversation sessions, requests, key discussions, and next steps.
- **[`features_and_changes.md`](./features_and_changes.md)**: Concise, high-efficiency logs of every feature, fix, or modification introduced—explaining **what** was built, **why**, and **how** it works in simple terms.

## Principles

1. **Simplicity First**: Clear explanations without unnecessary jargon.
2. **Efficiency**: Direct links to modified files, concise summaries, and minimal fluff.
3. **Continuous Updates**: Updated after every meaningful session or feature change.
